# Feel Good Spa — Admin Dashboard (Frontend)

Premium spa management console for Feel Good Spa. **Frontend only** — HTML, CSS, Bootstrap 5, and vanilla JavaScript. Sample data persists in `localStorage`.

## Open

1. Start any local static server from the project root, or open `admin/index.html` via your server.
2. Sign in with the prefilled demo account (any password works).
3. Explore Dashboard, Bookings, Calendar, Services, and the other modules.

Demo site login: `raymond@feelgoodspa.example` / `demo1234`

## Notes

- All figures are labelled as demonstration / sample data.
- Changes stay in the browser until you clear site data or use **Settings → Reset all demo data**.
- Public marketing pages live in the parent folder and are not modified by this admin UI.
- Brand colours and typography match the public Feel Good Spa site (navy, cream, gold · Cormorant Garamond + DM Sans).

## Stack

- Bootstrap 5.3 + Bootstrap Icons
- Chart.js (dashboard & reports)
- No PHP, MySQL, APIs, React, or build tools
