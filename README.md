# Feel Good Spa — Website Frontend

A complete spa and massage website for **Feel Good Spa**, restyled to match the luxury TravelBooking UI system (cream / navy / gold, Cormorant Garamond + DM Sans, topbar, sticky header, mobile drawer, centred hero with image card, destination-style cards, and editorial section patterns).

**Slogan:** Relax. Restore. Feel Good.

Built with HTML5, CSS3, Bootstrap 5 (CDN), Bootstrap Icons (CDN) and vanilla JavaScript only.

## Pages

- `index.html` — Home
- `about.html` — About
- `services.html` — Services with filters
- `service-details.html` — Dynamic details via `?service=`
- `packages.html` — Spa packages
- `gallery.html` — Gallery + lightbox
- `booking.html` — Booking form (demo validation)
- `contact.html` — Contact form + placeholders

## Assets

- `assets/css/style.css` — TravelBooking-inspired design system + spa additions
- `assets/js/script.js` — Navigation drawer, reveals, filters, lightbox, forms, service details

## How to open

Open `index.html` in a browser, or serve locally:

```bash
python -m http.server 5500
```

## Notes

- Contact details, WhatsApp and map are placeholders.
- Forms are frontend demos only — nothing is sent to a server.
- Guest reflections on the homepage are labelled as design placeholders.
